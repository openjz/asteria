    Direct3D 12 渲染管线运行顺序和顶点插值介绍

    本文目标：记住管线顺序，分清裁剪空间 / NDC / 屏幕空间，理解 PS 的 SV_Position 和普通属性的插值。

    一、管线总览

    IA
 → VS                      输入装配，把顶点组成点/线/三角形。
 →（可选：HS → TS → DS）    曲面细分三阶段，可选。
 →（可选：GS）              几何着色器，可选，按图元执行。
 → 光栅化阶段               裁剪、透视除法、视口变换、三角形设置、插值，并调用 PS。
 → PS                      像素着色器，逐像素执行。
 → OM                      输出合并阶段，做深度/模板测试、混合，写渲染目标。

    二、光栅化阶段内部顺序

    VS/GS 输出裁剪空间顶点
 → 齐次空间裁剪
 → 透视除法
 → 视口变换
 → 三角形设置
 → 光栅化 / 属性插值
 → 调用 PS

    1. 输入：裁剪空间

    VS/GS 输出的顶点是齐次裁剪空间坐标：

    (x_clip, y_clip, z_clip, w_clip)

    注意：这不是 NDC。投影变换后仍然是裁剪空间；NDC 要等透视除法之后才出现。

    2. 齐次空间裁剪

    在除以 w 之前，先在齐次空间把三角形裁剪到视锥内。这样可以正确处理 w <= 0 等情况。

    3. 透视除法

    x_ndc = x_clip / w_clip
y_ndc = y_clip / w_clip
z_ndc = z_clip / w_clip

    得到 NDC。NDC 的 z 通常在 [0, 1]。

    4. 视口变换

    把 NDC 映射到屏幕：

    • x_ndc, y_ndc → 屏幕像素坐标；
    • z_ndc → 深度范围（通常 [0, 1]）。

    这一步之后才是屏幕空间。

    5. 三角形设置与光栅化

    用屏幕空间的二维三角形顶点：

    • 建立边函数；
    • 判断每个像素/采样点是否被三角形覆盖；
    • 计算该像素的屏幕空间重心坐标；
    • 用重心坐标插值属性；
    • 调用 PS。

    三、PS 里的 SV_Position 是什么？

    PS 里如果声明：

    float4 PosH : SV_POSITION;

    那么 PS 拿到的 PosH 是屏幕空间坐标：

    • x, y：像素/采样点的屏幕坐标，是光栅化器确定的像素位置；
    • z：窗口深度，通常在 [0, 1]，通过屏幕空间重心坐标插值得到，但不做透视矫正。

    它不是 NDC 坐标。

    以下是 SV_Position 在各阶段的含义：

    阶段 SV_Position 的含义
    VS/GS 输出 裁剪空间 (x_clip, y_clip, z_clip, w_clip)
    光栅化内部 裁剪 → 除以 w → NDC → 视口变换
    PS 输入 屏幕空间 (像素 x, 像素 y, 深度 z)

    四、重心坐标是什么？

    用屏幕空间三角形的三个 (x, y) 顶点计算。

    对每个像素，得到三个权重：

    (λ0, λ1, λ2)
λ0 + λ1 + λ2 = 1

    可以把它理解为“这个像素受三个顶点影响的程度”：

    • 在顶点 V0 处：(1, 0, 0)；
    • 在边 V0V1 上：λ2 = 0；
    • 在三角形内部：三个权重都非负；
    • 在三角形重心处：(1/3, 1/3, 1/3)。

    注意：重心坐标不是“求重心”。它是一组权重；重心只是 (1/3, 1/3, 1/3) 这个特殊位置。

    重心坐标不需要在 PS 里自己算，光栅化器算好后用来插值。

    术语统一：本文说的“屏幕空间线性插值”，就是“用屏幕空间重心坐标插值”，两者是同一件事。

    text A(P) = λ0*A0 + λ1*A1 + λ2*A2

    重心坐标 λ0、λ1、λ2：

    • 深度：直接使用这个线性重心插值，不做透视矫正。
    • UV / 法线等属性：先做同样的重心插值，再做透视矫正；矫正后的最终结果在屏幕空间不再是线性的，但底层仍然是重心坐标插值，只是权重换成了 λ_i / w_i 并归一化。

    五、普通属性怎么进入 PS？

    以这些输入为例：

    struct PixelInput
{
    float4 PosH : SV_POSITION;
    float3 PosW : POSITION;
    float3 NormalW : NORMAL;
    float2 TexC : TEXCOORD;
    float4 Color : COLOR;
    bool IsFrontFace : SV_IsFrontFace;
};

    除了 SV_Position 和 SV_IsFrontFace，其余都是普通属性：

    • PosW：世界坐标；
    • NormalW：世界法线；
    • TexC：纹理坐标；
    • Color：颜色。

    它们的处理流程是：

    VS/GS 在每个顶点输出属性值
 → 光栅化器用屏幕空间重心坐标插值
 → 同时做透视矫正
 → PS 拿到矫正后的值

    也就是说，PS 里直接这样写即可：

    float4 c = diffuseMap.Sample(GetAnisoWrapSampler(), pin.TexC);

    不需要自己算重心坐标，也不需要自己除以 w 做透视矫正。

    插值修饰符

    修饰符 作用
    默认（linear） 透视矫正插值
    noperspective 关闭透视矫正，屏幕空间线性插值
    nointerpolation 不插值，整个图元用同一个值（flat）
    centroid 在像素覆盖区域内选代表点，不改变是否透视矫正
    sample 每个 sample 单独插值

    例如：

    noperspective float2 TexC : TEXCOORD;   // 关闭透视矫正
nointerpolation float3 NormalW : NORMAL; // 平面着色

    语义和插值方式是两回事

    • SV_Position、SV_IsFrontFace、SV_PrimitiveID 等带 SV_ 前缀的是系统值，由硬件特殊处理。
    • POSITION、NORMAL、TEXCOORD、COLOR 这些非 SV_ 语义只是 VS/PS 之间的用户通道名。
    • 一个属性叫 NORMAL 还是 TEXCOORD，不会改变它的插值方式；决定插值方式的是修饰符。
    • 普通 float 属性默认都做透视矫正，所以 PosW、NormalW、TexC、Color 都会自动矫正。

    六、深度的特殊情况

    深度和 UV/法线不一样：

    • 深度不做透视矫正；
    • 深度也是用屏幕空间重心坐标插值出来的，只是不做透视矫正；
    • 深度测试和写深度用的都是屏幕空间深度，不是裁剪空间 z。

    一个简单的记法：

    深度是“投影之后”的量，屏幕空间插值已经正确；
    UV、法线是“投影之前”的量，所以需要透视矫正。

    七、三条结论

    1. PS 里的 SV_POSITION 是屏幕空间坐标：x, y 是像素位置，z 是窗口深度，不是 NDC。
      插值前的三角形顶点，严格说是 VS/GS 输出的裁剪空间顶点；透视除法和视口变换后，才得到屏幕空间三角形。
    2. 屏幕空间重心坐标由屏幕空间三角形的三个 (x, y) 顶点计算。
    3. PosW、NormalW、TexC、Color 等普通属性在进入 PS 前，已经由渲染管线完成重心坐标插值 + 透视矫正，用户不需要手动做（SV_POSITION 中的 z 坐标也由渲染管线完成屏幕空间重心插值，只是不进行透视矫正）。

    八、一句话记忆

    VS/GS 输出裁剪空间 → 光栅化先裁剪 → 除以 w 得 NDC → 视口变换得屏幕空间 → 用屏幕三角形算重心坐标 → 普通属性插值并透视矫正 → PS。
    SV_Position 是屏幕空间坐标；深度不做透视矫正，UV/法线等普通属性默认做透视矫正。

    九、常见误区

    1. “VS 输出 NDC”：不对。VS/GS 输出裁剪空间，NDC 是光栅化阶段透视除法之后才有的。
    2. “PS 的 SV_Position 是 NDC”：不对。PS 拿到的是屏幕空间像素坐标 + 深度。
    3. “重心坐标就是求重心”：不对。重心坐标是三个权重，重心只是其中一个特殊点。
    4. “UV 要在 PS 里自己除以 w”：默认不需要。硬件插值已经做了透视矫正。
    5. “深度也要透视矫正”：不对。深度是投影后的量，屏幕空间线性插值即可。
    6. “语义名决定插值方式”：不对。语义只负责 VS/PS 连线；插值方式由 linear / noperspective / nointerpolation 等修饰符决定。
